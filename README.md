# 🍽️ Restaurant QA Automation Framework

A BDD test automation framework built with Selenium, Cucumber, and TestNG 
to validate core user journeys in a restaurant ordering system.

## 🛠️ Tech Stack
- **Java** — Core programming language
- **Selenium WebDriver** — UI browser automation
- **Cucumber** — BDD framework with Gherkin syntax
- **TestNG** — Test execution and reporting
- **REST Assured** — API testing
- **Maven** — Dependency management

## 📁 Project Structure
src/test/
├── features/          → Cucumber .feature files (test scenarios)
├── java/
│   ├── pages/         → Page Object classes (HomePage, MenuPage, CartPage)
│   ├── stepdefinitions/ → Cucumber step definitions
│   ├── runners/       → TestNG runner class
│   └── utils/         → Helper utilities
## ✅ Test Scenarios Covered
- User browses the restaurant menu
- User adds an item to the cart
- User completes checkout flow

## ▶️ How to Run
1. Clone the repo
2. Open in IntelliJ IDEA
3. Run `TestRunner.java` with TestNG
